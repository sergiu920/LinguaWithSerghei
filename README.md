# LinguaWithSerghei

LinguaWithSerghei is an interactive language-learning platform designed to make learning languages easier and more engaging through lessons, exercises, games, progress tracking, and AI-powered conversation practice.

## 🎯 Project Goals

- Provide structured language-learning experiences.
- Improve vocabulary and grammar through interactive exercises.
- Make learning engaging with educational games.
- Track learning progress and achievements.
- Offer AI-powered conversation practice.

## 🌍 Languages

- English (initial focus)
- German (planned)
- More languages to come.

## ✨ Planned Features

- User authentication and profiles
- Interactive lessons and exercises
- Vocabulary flashcards
- Grammar quizzes
- Educational games and challenges
- Learning progress and statistics
- AI-powered conversation practice

## 🛠️ Tech Stack - Backend

- NodeJs + ExpressJs
- TypeScript

## 🛠️ Tech Stack - Frontend

- TailwindCss
- shadcn/ui
- TypeScript
- React
